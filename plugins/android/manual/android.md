# 安卓模拟器（插件 android）

bridge 插件「安卓模拟器」（id `android`）在工作区里放一张「安卓」卡，把安卓模拟器（或用 USB / 无线调试连在服务器那台电脑上的真机）的实时画面放进 bridge：用户在卡里直接点按、滑动、打字，Claude 用 `mcp__android__android` 工具操作同一台设备，做安卓应用时能自己装包、点一遍、截图、读日志。本章讲它在哪、要什么环境、能做什么、Claude 怎么用、有什么限制。

## 在哪、谁能用

- Claude、ChatGPT（Codex）、Antigravity、dimensio 四个分页的右侧工作区都有「安卓」卡：桌面版在工作区工具开关的「⋮ 更多」里，手机上在工作区标签条里（手机 App 里点开是独立页面）。
- 只对主机（管理员）开放：模拟器吃内存和 CPU，还能装任意 apk。成员和公开快照的访客看不到这张卡，Claude 也只在主机的会话里拿到安卓工具。
- 它是插件，不是内置功能：在 设置 › 扩展 › 功能扩展 里安装（官方插件市场，或「添加 › 本机目录 / 上传 zip」），装上后同一处可以停用、卸载、改设置。需要 bridge 8.83 以上（插件接口六期：实时通道、工作区卡片进各分页）。
- 停用后卡片和工具都消失，已经开着的模拟器不会被关；再启用会重新接上。

## 需要的环境

- 服务器那台电脑上要有 Android SDK：platform-tools（adb）、emulator、cmdline-tools，至少一个系统镜像和一台虚拟设备（AVD）。装过 Android Studio 的一般都齐了。
- SDK 位置按「功能设置里填的 → ANDROID_HOME → ANDROID_SDK_ROOT → %LOCALAPPDATA%\Android\Sdk」的顺序找。
- Windows 上要开硬件加速（「Windows 虚拟机监控程序平台」），否则模拟器跑不动；Docker、WSL2 可以共存。
- 缺东西时卡片空态会说明；也可以让 Claude 调 `android` 工具的 doctor 体检，它会给出安装步骤。接受 SDK 许可、下载镜像（约 1.6 GB）前 Claude 会先问用户。

## 卡片怎么用

- 顶部设备按钮：选当前设备（在线设备 + 可启动的虚拟设备），点虚拟设备名即启动；第一次冷启动约 20 秒，之后从快照启动约 5 秒。
- 画面：鼠标左键 = 点按 / 拖动，右键 = 返回，中键 = 主页，滚轮 = 滚动；手机上手指直接操作，支持多指。
- 键盘：在电脑上点过画面后直接打字；中文用自己电脑的输入法打，选好的字会粘贴进设备；Ctrl+V 粘贴电脑剪贴板，在设备里复制的内容会回到电脑剪贴板。手机上点工具条的键盘按钮唤起本机键盘，也可以直接用模拟器里的软键盘。
- 工具条：返回、主屏幕、最近任务、旋转；「⋮」里有电源键、音量、下拉通知栏、截图、关闭模拟器。
- Claude 在操作时，画面上方会出现「Claude 操作中」，点按的位置会闪一圈。用户随时可以直接在画面上操作接管，Claude 下一步会被告知「用户刚动过」。
- 子页（Android Studio 式）：Logcat（按级别 / 应用 / 关键词过滤、暂停、清空）、应用（启动、结束、清数据、卸载，拖 apk 进来安装）、文件（浏览设备文件、下载、上传）、控制（模拟器专属：定位、电池、旋转、折叠、短信、来电、指纹、网速）、快照（存、恢复、删除）、控件树（列出界面元素，选中时在画面上框出来）。卡片放宽时画面与子页左右并排。
- 新建虚拟设备：设备菜单底部「新建虚拟设备…」，选机型和已装的系统镜像；虚拟设备的「⋯」里有冷启动、清空数据并启动、删除。
- 无线连接手机：设备菜单里「无线连接手机…」。手机上打开 开发者选项 › 无线调试 ›「使用配对码配对设备」，把屏幕上的 IP、端口、6 位配对码填进来配对，再填无线调试页上的 IP 和端口连接；手机要和服务器在同一个局域网。
- 录屏：「⋮」里「开始录屏 / 停止录屏」，最长 3 分钟，停止后下载 mp4。

## Claude 的安卓工具

- 工具名 `mcp__android__android`，一个工具、按 action 区分：doctor、devices、start、stop、create_avd、install、launch、stop_app、open_url、apps、clear_data、uninstall、screen、ui_tree、tap、long_press、swipe、scroll、input、key、wait、logs、emu、snapshot、record（录屏存进工作空间）。
- dimensio、Antigravity、ChatGPT（Codex）也有同一个工具（经 bridge 插件工具通道，名字带插件前缀），只在主机的会话里给。ChatGPT（Codex）的工具在 bridge_plugins 服务下，新开的 Codex 对话生效。
- screen 返回截图（可交互元素框上编号）和元素清单；tap 可以按编号、按文字或按截图坐标点。点按、输入等动作做完默认带回新画面。
- 做安卓应用的闭环：Claude 用自己的 Bash 在项目里跑 gradlew 构建 → install 装 apk → launch → screen 核对 → 交互 → logs 查崩溃 → 改代码再来。
- 多步界面操作或测试，Claude 会交给子 agent「android-operator」（安卓操作员），截图不堆进主对话。
- 护栏：接受 SDK 许可、建 / 删虚拟设备、清应用数据、卸载应用、在真机上发短信打电话之前先问用户。
- 「给 Claude 安卓工具」可以在功能设置里单独关掉，卡片照常能用。

## 模拟器的生命周期

- 模拟器不在服务器桌面上弹窗口，也不从服务器喇叭出声；画面只在卡片里。
- bridge 重启（含自更新）不会关模拟器，重启后自动认领，卡片接着能用。
- 没人看、Claude 也没动它超过设定时长（默认 30 分钟，功能设置里可改，0 = 不自动关）就关机，关机前存快照，下次几秒开好。
- 同时最多开几台（默认 2）在功能设置里改。卡片只会关 bridge 自己开的模拟器；Android Studio 开的可以看、可以操作，但 bridge 不会去关它。

## 功能设置

设置 › 扩展 › 功能扩展 ›「安卓模拟器」：Android SDK 位置、画质（流畅 / 标准 / 高清，经隧道用手机看选流畅）、无人使用多少分钟后自动关、最多同时开几台、给 agent 安卓工具。

## 限制与常见问题

- 画面需要浏览器支持 WebCodecs：Chrome、Edge、bridge 桌面客户端和安卓 app 都可以；不支持时卡片会提示。
- 真机要在手机上打开「USB 调试」并点「允许」；状态是 unauthorized 时卡片和工具都会提示。真机用不了「控制」「快照」两页（那是模拟器专属）。
- 没有声音转发、没有断点调试、Profiler 和 Compose 预览。
- 只在 Windows 服务器上验证过；macOS / Linux 服务器理论上可用（同一套 SDK 工具）但没有实测。
- 有的应用会检测模拟器（部分银行、游戏），在模拟器里打不开或功能受限。
