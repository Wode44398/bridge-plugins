# QQ 机器人（bridge 插件）

把 QQ 群和私聊接到 bridge 里的 Claude：群友 @ 机器人或发「/ai 问题」，Claude 的回答直接发回 QQ。

- **不需要建账号、不需要开多用户**：每个群 / 私聊自动分到一个独立沙箱（插件数据目录 `sandboxes/<g群号|p QQ号>/`），
  里面没有命令行，读不到你电脑上的其它文件，也读不到别的群。Claude 能联网查资料，也能在自己的沙箱里读写文件。
- 用的是你 bridge 自己的 Claude 登录 / 号池；每天最多回答几轮可以设（默认 300），详情页能看到今天用了多少。
- 同一个群的问题排队一个一个答（大家共用一段对话，Claude 知道每句话是谁说的）；不同的群可以同时答。
- 只用插件公共接口（pluginApi 3），不碰 bridge 内部模块：bridge 升级不会把它弄坏。

## 安装

设置 › 扩展 › 功能扩展 › 添加：上传本插件的 zip、填 GitHub 地址，或登记本机目录。装好后设置侧栏多一组「插件 › QQ 机器人」。
要求 bridge 的插件接口 v3。

## 第一次设置（三步）

QQ 机器人账号要靠协议端 [NapCat](https://napneko.github.io/) 挂在电脑上。准备一个当机器人的 QQ 小号，下载 NapCat.Shell 解压到随便哪个目录。

1. 打开「设置 › 插件 › QQ 机器人」控制台，切到「设置」：「协议端」保持「由 bridge 拉起」，「NapCat 目录」填解压的位置。
2. 回到控制台顶部点「扫码登录 / 换号」，用小号的手机 QQ 扫出现的二维码。
3. 在「群和私聊」里点要回答的群，打开「本群回答」。

NapCat 的网络配置（发消息用的 HTTP 服务器、收消息的上报地址、token）插件会在启动它之前自动写好，不用进 NapCat 的 WebUI。
扫码登上后这个号会记下来，以后重启自动快速登录；QQ 掉线时先自动重启重登，救不回来推送通知让你再扫一次。

NapCat 你想自己跑（比如在另一台电脑上）：「协议端」选「已经在跑」，在 NapCat 的 WebUI › 网络配置里加「HTTP 服务器」（端口 3000，可设 token）
和「HTTP 客户端」（地址填控制台显示的上报地址，消息格式选 Array；不在同一台电脑时两边设同一个「上报 Token」），再把地址和 token 填进插件设置。

## 用法

| 在 QQ 里 | 效果 |
|---|---|
| `@机器人 问题` 或 `/ai 问题` | 回答（引用回复提问的那条，并 @ 提问的人） |
| 引用一条消息再 @机器人 | 被引用的原话和里面的图一起交给 Claude |
| 发图 + @机器人 | Claude 看图回答 |
| 私聊机器人 | 直接回答，不用 @ 或前缀 |
| `@机器人 /chat` | 发一个专属对话页链接，在网页上单独和 Claude 聊 |
| `/ai 重置` | 本群开一段新对话（群主、群管理或设置里的「管理员 QQ」才能用） |
| `/ai 暂停` / `/ai 继续` | 让机器人在所有群闭嘴 / 恢复（同上，管理才能用） |

- 回答较长时折成一张「聊天记录」合并转发卡片（可按群设成总是 / 从不）。
- Claude 做的文件（文档、代码、图片……）直接发进 QQ：图片发图，其它上传成群文件 / 私聊文件。
- 开着「记录群聊」时，群里所有消息（含图片）按天记进这个群的沙箱（`群聊记录/日期.txt`、`群聊记录/图片/日期/`），
  群友说「上面那个」「刚才那张图」时 Claude 自己翻。图片按「群聊图片保留几天」每天凌晨清理，文字一直留着。

## 发版公告

设置「发版公告」里填要关注的 GitHub 仓库（一行一个 `owner/repo 显示名`）、选要发的群：这些仓库发布新的正式版时，
机器人在群里发一条「📢 某某 发布新版本 vX」+ 3～5 条更新要点（Claude 读发布说明归纳，也可以改成直接取说明开头）+ 下载链接。

- 每 5 分钟查一次（未登录的 GitHub 接口，带 ETag，没变化不占额度）；只认已公开的 Release，草稿和预发布不发（预发布可以打开）。
- 刚加进来的仓库，已有的版本只记下、不发；发布超过 3 天才查到的不再当新版本。
- QQ 不在线或机器人暂停时公告先留着，恢复后补发（一天内）；公告也记进群聊记录，群友问「更新了啥」Claude 翻得到。
- 详情页按钮：「检查新版本」马上查一遍；「预览发版公告」拼一条给你看、不发群；「补发最新版公告」把最新正式版发到选的群。

## 控制台

「插件 › QQ 机器人」面板（手机上也能开）：各群 / 私聊的问答记录、Claude 那边的完整对话、专属对话页的转录；
暂停开关、今天的用量；以机器人身份手动发一条，或者重开某个群的对话。

## 数据在哪

`<bridge 数据根>/plugin-data/qqchatbot/`：`sandboxes/` 各聊天的沙箱，`logs/` 控制台记录与插件日志，`chat-sessions.json` 聊天 → Claude 会话，
`chat-usage.json` 用量。卸载插件不会删这些。
